How it works

Know what your agent is doing. Before it does it.

Every time your agent reaches for a tool, we check the action against how that agent normally works. Then we allow it, hold it for a person, or block it. The tool runs only if we say yes.

No AI. No GPU. No tokens.

One action, start to finish

Every action stops here first.

Agent platforms have a step where a tool call is ready but hasn’t run. A small connector puts us at that step. We score the action and send the answer back. Only then does anything reach the world.

The method

Observe. Learn. Score.

Your agent’s own behavior is the reference. We don’t write rules about what it should do. We measure what it actually does.

  1. 01

    Observe.

    We record each action your agent takes: which tool, in what order. Not its prompts, messages or files.

  2. 02

    Learn its baseline.

    From those actions we build a statistical picture of how this agent normally works. Every agent gets its own.

  3. 03

    Score each new action.

    Before an action runs, we check how well it fits that baseline. If it fits, it runs. If it doesn’t, it’s held for a person or blocked.

  4. 04

    Keep learning.

    When a person marks a block right or wrong, that agent’s baseline updates. Other agents are unaffected.

It’s statistics on behavior, the same family of methods long used to catch fraud. No AI models in the loop.

One run, step by step

Three fit. One is new. One doesn’t fit.

  • Steps 1 to 3 match how this agent works, so they run.
  • Step 4 is new for this agent. It waits for a person.
  • Step 5 doesn’t fit its baseline. It’s blocked before it runs, and the agent gets the reason.

Using it

Most of the time, you won’t notice it.

There are no rules to write. Actions that fit run as usual. You hear from us only when one doesn’t.

ALLOW

It runs.

The tool runs and returns its result. Nothing changes for you or the agent.

HOLD

A person decides.

The action waits. Someone on your team approves it once or keeps it blocked. Nothing runs until then.

BLOCK

It never runs.

The agent gets Blocked by Agentic GUARDIANS back instead of a result, with the reason.

You teach it. Review a block and mark it right or wrong. That agent’s baseline learns. Other agents are unaffected.

No system is perfect. That’s why holds go to a person, and every block can be reviewed.

What we read

We read actions, not prompts.

An attack on an agent usually arrives as text: a hidden instruction in a file, a page or a message. We don’t read that text. We look at what the agent does next.

What we look at

  • Which tool the agent calls
  • In what order
  • Compared with that agent’s own baseline

What we don’t read or store

  • Prompts
  • Messages
  • Files

The weight

No AI. No GPU. No tokens.

  • No AI models in the loop. The decision is math on behavior. There is nothing to prompt and nothing to talk around.
  • Runs on a lightweight CPU, on your machine. Nothing leaves it.
  • No GPU bill. No token bill. Checking an action doesn’t mean paying for another model to think.
