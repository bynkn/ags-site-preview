How it works

Agents drift. They make things up. They get weaponized. Then they act.

The issue

A compromised agent doesn’t look compromised.

Every credential is valid. Every access is authorized.

But its intent has completely changed.

The paradigm

AI can’t watch AI.

Yet the industry’s answer is AI guarding AI. A prompt that misleads the agent can mislead the guard.

  • Identity and accessVerifies credentials, not intent.
  • Prompt filters and guardrailsInspect language, so a prompt can reach them too.
  • Logs and monitoringFind it after it happened.

  • AI supervising AIAnother probabilistic layer that can be misled.

How it works

Five steps. One loop.

It scores the sequence of tool calls: which tool, in what order, against that agent’s own history. It never reads the arguments or commands.

  1. 1

    Connect. One small plugin sees every action before it runs.

  2. 2

    Learn. We learn each agent’s normal from its own behavior and work. No rules to write.

  3. 3

    Spot the drift. We check every action against its fingerprint, with math.

  4. 4

    Stop. Allow it, hold it for a person, or block it, before it runs. Every block comes with the reason.

  5. 5

    Prove. Blocks and holds can carry a signed record (Ed25519), chained so any tampering shows. Verify it with our public key.

The tool call never runs. The agent gets Blocked by Agentic GUARDIANS back instead of a result.

When an action is blocked, a person can review it in the console and mark it right or wrong, and the agent’s baseline learns from that.
