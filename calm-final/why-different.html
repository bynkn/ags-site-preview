Why it’s different

Do you know what your agent did today?

  • Agents drift.
  • They make things up.
  • They get weaponized.
  • Then they act.

You’ll never know what it did. Until it’s too late.

The quiet failure

A compromised agent doesn’t look compromised.

Same keys. Same access. Someone else’s intent.

A hidden instruction in a file can change what an agent does. Every credential is still valid, so every check passes. Logs show the damage after it happened.

Today’s tools

Today’s tools check who the agent is, what it says, or what already happened.

Not behavior or intent. Not what it’s about to do.

Identity and accessChecks credentials, not intent. A hijacked agent still has valid keys.
Prompt filters and guardrailsInspect language, so a prompt can reach them too.
Logs and monitoringFind it after it happened.
Manual reviewToo slow for machine speed.
AI supervising AIAnother layer that reads the same text, and can be misled the same way.
Large platformsOften complex, and built for companies with a security department.

The paradigm

AI can’t watch AI.

Yet the common answer is AI guarding AI. A prompt that misleads the agent can mislead the guard. That puts the lock and the thief in the same paradigm.

It also means more models, more tokens and more GPUs, just to check the first model.

Why we chose this

Five decisions, and the reason for each.

No AI in the decision.

A model can be persuaded. Math can’t. There is nothing to prompt and nothing to talk around.

We don’t read prompts.

Attacks arrive as text. If we never read the text, it can’t reach us.

One baseline per agent.

What’s normal for one agent is strange for another. So each agent is measured against itself.

Fail closed.

If we can’t check an action, it doesn’t run. A guard that steps aside when it’s down isn’t a guard.

On your machine.

Your agent’s actions are your business. It runs on a lightweight CPU, on your machine. Nothing leaves it.

The weight

No AI. No GPU. No tokens.

  • No AI models in the loop. The decision is math on behavior. There is nothing to prompt and nothing to talk around.
  • Runs on a lightweight CPU, on your machine. Nothing leaves it.
  • No GPU bill. No token bill. Checking an action doesn’t mean paying for another model to think.

Trust the behavior. Block the rest.
